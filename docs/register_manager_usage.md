# 寄存器管理界面使用说明

## 概述

寄存器管理界面是一个基于JSON配置文件的自动化界面生成系统，用于管理下位机的107个32位小端序寄存器。该系统支持三种类型的寄存器：配置寄存器（可读写）、状态寄存器（只读）和命令寄存器（只写）。

## 功能特性

### 1. 自动界面生成
- 基于JSON配置文件自动生成寄存器管理界面
- 支持多种数据类型的自动转换和显示
- 提供美观的用户界面和良好的用户体验

### 2. 数据类型支持
- `uint32_t`: 32位无符号整数
- `int32_t`: 32位有符号整数
- `uint16_t`: 16位无符号整数（占用完整32位寄存器）
- `int16_t`: 16位有符号整数（占用完整32位寄存器）
- `fixed_point`: 定点数（浮点数*缩放倍数存储）
- `dual_uint16`: 两个uint16_t组合（如端口号）
- `ipv4`: IPv4地址（以uint32_t存储）

### 3. 界面功能
- **状态寄存器**: 实时显示当前值和单位
- **配置寄存器**: 提供设置按钮和输入框，支持二次确认
- **命令寄存器**: 提供命令按钮，支持快捷键和二次确认

## JSON配置文件格式

### 基本结构
```json
{
  "registers": [...],        // 配置寄存器列表
  "status_registers": [...], // 状态寄存器列表
  "commands": [...]          // 命令寄存器列表
}
```

### 寄存器配置字段

#### 必需字段
- `var_name`: 寄存器变量名
- `permission`: 读写权限（"r"=只读，"rw"=读写，"w"=只写）
- `address`: 寄存器地址（0-106）
- `data_type`: 数据类型
- `range`: 有效值范围 [最小值, 最大值]
- `unit`: 数值单位字符串

#### 可选字段
- `alias`: 寄存器别名（显示名称）
- `scale_factor`: 缩放倍数（定点数类型，默认100000）
- `confirm_dialog`: 设置时是否需要二次确认（布尔值）
- `step_size`: SpinBox步长（整数最小1，定点数默认0.1）
- `command_value`: 命令值（仅命令寄存器）
- `hotkey`: 快捷键（可选）
- `qss_file_path`: 自定义样式文件路径（可选）

### 配置示例

#### 配置寄存器示例
```json
{
  "var_name": "PID_Speed_Kp",
  "alias": "速度环Kp",
  "permission": "rw",
  "address": 15,
  "data_type": "fixed_point",
  "scale_factor": 100000,
  "range": [0.0, 1000.0],
  "unit": "",
  "confirm_dialog": true,
  "step_size": 0.001
}
```

#### 状态寄存器示例
```json
{
  "var_name": "Ia",
  "alias": "A相电流",
  "permission": "r",
  "address": 73,
  "data_type": "fixed_point",
  "scale_factor": 100000,
  "unit": "A"
}
```

#### 命令寄存器示例
```json
{
  "var_name": "START_CMD",
  "alias": "启动命令",
  "permission": "w",
  "address": 105,
  "data_type": "uint32_t",
  "command_value": 193,
  "unit": "",
  "confirm_dialog": true,
  "hotkey": "F1"
}
```

## 使用方法

### 1. 配置文件准备
1. 复制 `config/registers_config_example.json` 为 `config/registers_config.json`
2. 根据实际需求修改配置文件
3. 确保所有寄存器地址、数据类型和范围正确

### 2. 界面操作

#### 配置寄存器操作
1. 在输入框中输入新值
2. 点击"设置"按钮
3. 如果启用了二次确认，会弹出确认对话框
4. 确认后发送到下位机

#### 状态寄存器查看
- 状态寄存器会自动显示从下位机接收到的实时数据
- 双击当前值可以将值复制到剪贴板（如果是配置寄存器）

#### 命令发送
1. 点击命令按钮
2. 如果启用了二次确认，会弹出确认对话框
3. 确认后发送命令到下位机

### 3. 快捷键
- 可以为命令按钮设置快捷键（如F1、F2等）
- 快捷键会显示在按钮的工具提示中

## 数据转换规则

### 定点数转换
- 下位机使用: `FLOAT_TO_U32_FIXED_POINT(fp32_var) = (uint32_t)((int32_t)((fp32_var) * (100000)))`
- 上位机使用: `U32_FIXED_POINT_TO_FLOAT(u32_var) = ((int32_t)(u32_var)) * 0.00001f`

### IPv4地址转换
- 存储格式: 小端序uint32_t
- 显示格式: "192.168.1.1"

### 双uint16转换
- 存储格式: 高16位:低16位
- 显示格式: "high:low"

## 故障排除

### 常见问题

1. **配置文件加载失败**
   - 检查JSON格式是否正确
   - 确认文件路径是否存在
   - 查看日志文件获取详细错误信息

2. **寄存器设置失败**
   - 检查网络连接
   - 确认下位机是否在线
   - 验证寄存器地址和数据范围

3. **界面显示异常**
   - 检查QSS样式文件是否存在
   - 确认数据类型配置是否正确

### 日志查看
- 程序运行日志保存在 `oscilloscope.log` 文件中
- 可以通过日志查看详细的错误信息和调试信息

## 扩展功能

### 自定义样式
- 可以为特定寄存器指定自定义QSS样式文件
- 样式文件路径在配置中通过 `qss_file_path` 字段指定

### 批量操作
- 支持批量设置多个寄存器（通过编程接口）
- 支持配置文件的热重载

## 技术架构

### 主要组件
- `RegisterManagerWidget`: 主界面管理器
- `RegisterWidget`: 单个寄存器控件
- `RegisterDataConverter`: 数据转换器
- `RegisterIntegration`: 集成模块

### 信号机制
- 使用Qt信号槽机制进行组件间通信
- 支持异步操作，避免界面阻塞

### 数据流
1. 下位机 → UDP接收器 → 寄存器管理界面（状态更新）
2. 寄存器管理界面 → UDP发送器 → 下位机（配置设置）
